# Reference

Package notes explain responsibilities, ownership, and design. The **API**
section is generated from `src/app` on every documentation build: signatures,
type annotations, and docstrings come directly from the source.

Start with [Architecture](../architecture.md) for cross-layer workflows, or
browse the [generated API](api/index.md) for individual modules.

Generated pages are not edited or committed. Improve API explanations in
Python docstrings; keep diagrams and cross-component design notes in the
handwritten package pages. See the [authoring workflow](../development.md#reference-authoring).
