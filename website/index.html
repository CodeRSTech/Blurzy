Blurzy

Detect. Track. Review. Blur.

A Qt desktop workflow for detecting and tracking subjects in video, editing annotations, and exporting video with selected subjects blurred.

Read the documentation Get started View source on GitHub

One workflow, from video to export

  • Review video with playback and frame-level controls.
  • Detect and track subjects using supported model providers.
  • Edit bounding boxes and import or export annotation data.
  • Export blurred video while background workers report progress.

Built through hands-on prototyping

Version 1.2.0: read the changelog.

Blurzy is an early-stage project, not a stable release. Model availability depends on provider installations, weights, and hardware support. Always review annotations and exported video for missed subjects.
